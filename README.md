O Versionamento Semântico é um padrão usado para organizar e identificar as versões de um software através de números, facilitando o controle das mudanças que foram feitas no projeto.

O formato utilizado é **MAJOR.MINOR.PATCH** (exemplo: `v1.0.0`), onde cada número tem um significado:

**MAJOR (Principal):** É incrementado quando são feitas mudanças grandes que quebram a compatibilidade com as versões anteriores.
**MINOR (Secundária):** É incrementado quando adicionamos novas funcionalidades, mas que continuam compatíveis com o que já existia.
**PATCH (Correção):** É incrementado quando apenas corrigimos bugs ou pequenos erros, sem adicionar novas funções e sem quebrar nada.
